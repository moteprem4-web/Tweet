Tweet is a Twitter-inspired web application built with Django, Bootstrap, and HTML, allowing users to post, edit, and delete tweets with images. Only authenticated users can manage their own tweets. The project also includes a fully configured Django admin panel for content and user management.

🚀 Features

*Authentication

User registration, login, and logout

Only authenticated users can post, edit, or delete tweets

*Tweet Management

Post tweets with text and optional images

Edit or delete only your own tweets

Authorization ensures users cannot modify others’ content

*Feed

Browse all tweets in a responsive home feed

Posts are displayed in chronological order

*Admin Panel

Fully functional Django admin for managing users and tweets

Admin can view, edit, or delete any tweet

*Frontend

Responsive and modern design using Bootstrap

Mobile-friendly layout and interactive UI
